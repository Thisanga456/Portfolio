### 1. EkataYan Deep Dive

**Core Problem:**
EkataYan solves the problems that groups face when planning trips in Sri Lanka. Trip information is usually scattered across WhatsApp chats, spreadsheets, expense notes, weather apps, and different search tabs. This makes it difficult for groups to agree on an itinerary, manage expenses, discover places, and keep everyone updated in one place.

**My Role:**
EkataYan was a team project for the IIT InfoSchol induction programme. I worked mainly as the **Full-Stack Developer**, with a stronger focus on the backend.

My responsibilities included:

* Developing the Flask backend and REST API
* Working with Supabase for database, authentication, storage, and realtime functionality
* Integrating the backend with the Kotlin Android application using Retrofit
* Working on the AI itinerary generation functionality
* Implementing the group/trip and expense-related functionality
* Helping integrate and connect the different parts of the application

The project team was Team #5, and EkataYan achieved **1st Runner-Up at the IIT InfoSchol Demo Day**.

**Key Features:**

* AI-powered personalized Sri Lankan trip itinerary generation
* Group Hub for managing trips and coordinating with group members
* Shared LKR expense tracking and settlement
* Trip discovery, wishlist, weather information, and group planning
* Trip invitation and notification functionality

**Technical Challenges & Solutions:**

1. **AI itinerary generation:** We initially experimented with different AI models, but the output quality and integration were inconsistent. We tested multiple approaches and eventually used Gemini because it produced more suitable structured travel-planning responses for the application.

2. **Realtime group functionality:** We needed users to receive trip invitation/notification updates without manually refreshing the application. We implemented a notification system using Supabase database triggers, realtime functionality, RLS policies, and a unique index to prevent duplicate notifications.

**Tech Stack:**
Kotlin, Android XML, MVVM, Retrofit, Flask, Python, Supabase, REST API, Gemini AI, Railway.
